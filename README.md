# India Tourism 2025 -- Data Analysis

## 📌 Project Overview

This project analyzes the **India Tourism 2025** dataset using Python to
understand tourist trends, tourism revenue, seasonality, visitor types,
and other tourism-related patterns across Indian states and months.

The project covers the complete data analysis workflow, including **data
cleaning, data transformation, exploratory data analysis (EDA),
statistical analysis, and data visualization**.

## 🎯 Objectives

-   Analyze domestic and foreign tourist trends.
-   Identify states with the highest tourist volume.
-   Identify top-performing states based on tourism revenue.
-   Analyze monthly tourism patterns and seasonality.
-   Compare domestic and foreign tourists.
-   Analyze revenue generated per tourist.
-   Understand the relationship between tourist volume and tourism
    revenue.
-   Analyze tourism growth patterns.
-   Explore the purpose of tourist visits.

## 🛠️ Technologies & Libraries

-   Python
-   Pandas
-   NumPy
-   Matplotlib
-   Seaborn
-   Jupyter Notebook / VS Code

## 📂 Dataset

**Dataset:** India Tourism 2025

The dataset contains tourism-related information such as:

-   Month

-   Total Tourists
-   Tourism Revenue
-   Revenue per Tourist

-   Seasonality
-   Purpose of Visit
-   Growth Percentage

## 🔄 Project Workflow

### 1. Data Loading

The dataset was imported into Python using Pandas.

### 2. Data Cleaning

The dataset was checked and cleaned for:

-   Missing values
-   Duplicate records
-   Incorrect data types
-   Date formatting
-   Column names
-   Data consistency

### 3. Data Transformation

Additional columns and calculated metrics were created to make the
dataset suitable for analysis.

Examples include:

-   Domestic Tourist Percentage
-   Foreign Tourist Percentage
-   Revenue-related calculations
-   Date and month-based analysis

### 4. Exploratory Data Analysis (EDA)

The dataset was analyzed to answer questions such as:

-   Which states receive the most tourists?
-   Which states generate the highest tourism revenue?
-   Which months have the highest tourist volume?
-   How do domestic and foreign tourists compare?
-   Which states have higher revenue per tourist?
-   Is there a relationship between tourist volume and revenue?
-   How does tourism vary by purpose of visit?
-   Which states/months show higher or lower growth?

### 5. Data Visualization

Charts were created using Matplotlib and Seaborn to present insights
clearly.

Visualizations include:

-   Bar charts
-   Line charts
-   Histograms
-   Scatter plots
-   Heatmaps
-   Comparative charts

## 📊 Key Analysis Areas

### Tourist Volume

Analysis of total, domestic, and foreign tourist arrivals across states
and months.

### Tourism Revenue

Comparison of revenue generated by different states and tourism periods.

### Seasonality

Identification of high and low tourism periods throughout the year.

### Tourist Volume vs Revenue

Correlation analysis to understand whether higher tourist volume is
associated with higher tourism revenue.

### Growth Analysis

Analysis of approximate tourism growth across states and periods.

## 📈 Project Outcome

This project demonstrates how Python can be used to transform raw
tourism data into meaningful insights through:

**Data Cleaning → Data Transformation → EDA → Statistical Analysis →
Visualization**

The analysis can help understand tourism performance, visitor patterns,
revenue generation, and seasonal trends across India.
